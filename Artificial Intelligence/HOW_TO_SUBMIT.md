# Submitting the CodeAlpha AI projects

Each folder in this package is a separate project and should become its **own GitHub repository** with exactly this name (CodeAlpha asks for `CodeAlpha_ProjectName`):

| Task | Repository name |
| --- | --- |
| 1. Language Translation Tool | `CodeAlpha_LanguageTranslationTool` |
| 2. Chatbot for FAQs | `CodeAlpha_FAQChatbot` |
| 3. Music Generation with AI | `CodeAlpha_MusicGenerationAI` |
| 4. Object Detection and Tracking | `CodeAlpha_ObjectDetectionTracking` |

## Push one project to GitHub

Create an empty repository with that name on github.com (no README, no .gitignore), then, from inside the project folder:

```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/CodeAlpha_FAQChatbot.git
git push -u origin main
```

## The rest of the checklist (from the CodeAlpha instructions)

1. Post your internship status on LinkedIn and tag **@CodeAlpha**.
2. Post a video explaining each project, with the GitHub link.
3. Submit each completed task through the submission form shared in your WhatsApp group.

Before you record the video, run each project once and read the "How it works" part of its README. The code is commented, and the README explains each step in plain words.
