# CodeAlpha_PhishingAwarenessTraining

An interactive phishing awareness module, built for **Task 2 (Phishing Awareness Training)** of the CodeAlpha Cyber Security Internship.

It is a single self-contained file (`index.html`). There is nothing to install, it works offline, and nothing you type leaves your browser.

## Run it

Open `index.html` in any modern browser.

To publish it as an online module, push this repository to GitHub, then go to **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`. The module appears at `https://<your-username>.github.io/CodeAlpha_PhishingAwarenessTraining/`.

## What it covers

| Task 2 requirement | Where in the module |
|---|---|
| Recognise phishing emails | **Find the red flags**: a fake bank email with six clickable giveaways |
| Recognise fake websites | **Check a link**: how to read a web address, plus a link checker that explains each red flag it finds |
| Social engineering tactics | **How attackers work on people**: six psychological levers and six delivery channels (spear phishing, smishing, vishing, quishing, BEC, clone phishing) |
| Real-world examples | **Real cases**: RSA 2011, fake invoices 2013 to 2015, Twitter 2020, Uber 2022, MGM 2023, and the everyday KYC / refund / parcel-fee scam |
| Best practices and tips | **Stay safe**: the SLAM check, habits, what to do after a click, where to report |
| Interactive quizzes | **Test yourself**: eight scenarios with instant feedback, a score and topics to review |

## Notes

- The organisations in the sample email and quiz are made up. The real cases are summarised from public company statements and court or regulator documents, so check the originals before quoting details.
- The link checker is a teaching aid built on simple rules. A clean result is not proof that a link is safe.
- The page follows the system light or dark setting, works on phones, and can be used with a keyboard.
